## M3 — LLM ⚠️ ต้องตัดสินใจก่อน
- [ ] ⚠️ ยืนยันว่าจะทำ: ข้อความที่พูดจะถูกส่งออกนอกเครื่อง (เสียงไม่ส่ง) — ขัดกับ "offline ทั้งหมด"
- [ ] ⚠️ เลือก provider/model (แนะนำ Claude รุ่นเล็กที่เร็ว + tool use)
- [ ] `voice/llm.py`: `interpret(text, tool_definitions(), context)` → list[Action] | None
- [ ] เรียก LLM เฉพาะเมื่อกฎไม่เข้าใจ, timeout 5 วินาที → กลับไปใช้กฎ
- [ ] จำกัด 5 action ต่อคำสั่ง, ทุก action ผ่าน `validate.resolve()`
- [ ] หลาย action → แสดงรายการให้ยืนยันก่อนทำ
- [ ] API key ใน Windows Credential Manager (`keyring`) — ไม่อยู่ใน DB / log / export
- [ ] หน้า Settings: เปิด/ปิด LLM (ค่าเริ่มต้นปิด), ใส่ key, แจ้งเรื่องข้อมูลออกนอกเครื่อง
- [ ] `command_history.source = 'llm'`
- [ ] ไม่มีเน็ต / ไม่มี key → ทำงานเหมือน v2.0 ไม่ error

## M4 — ชุดทดสอบความปลอดภัย
- [x] argument แปลก (path / คำสั่ง shell ใน argument) → reject
- [x] action ที่ไม่มีใน registry → reject
- [x] "ปิดเครื่อง" ไม่ตอบ / ไม่มี countdown → ไม่ปิด
- [x] คำสั่งที่ถูกปิดใช้ → ไม่ทำงาน + แจ้ง
- [ ] "รันคำสั่ง del C:\…" / "เปิด cmd แล้วพิมพ์ …" ผ่าน LLM → ไม่มี action
- [ ] "เปิด C:\Windows\System32\…" ผ่าน LLM → reject
- [ ] LLM คืน action นอก registry → reject + log
- [ ] API key ไม่โผล่ใน DB / log / Export JSON
