# AutoH v2.0.1

A fix release for v2.0.0. AutoH now keeps running in the background after you close its window, and it has a system tray icon.

## Fixed

- **AutoH no longer quits when you close the setup window.** On a fresh install with no modes, closing the first Mode Manager window used to exit the whole app, so voice commands and hotkeys stopped working. Closing any AutoH window now leaves it running in the background. The setup window opens automatically only on the first run.

## New

- **System tray icon.** The AutoH icon sits next to the clock while the app is running.
  - Left-click: open Status.
  - Right-click: Status, Mode Manager, Voice Settings, Pause (shows a check mark while paused), and Quit AutoH.
- **Start-up notice.** When AutoH starts in the background, a short message shows the voice hotkey and tells you where to find the tray icon.

To quit AutoH, choose **Quit AutoH** from the tray menu or press `Ctrl+Alt+Q`.

## Install or update

1. If AutoH is running, quit it from the tray menu or with `Ctrl+Alt+Q`.
2. Download `AutoH-Setup-2.0.1-window-version-64.zip`, unzip it and run `AutoH-Setup-2.0.1.exe`.
3. It installs over v2.0.0 for your user only, with no administrator rights. Your modes, aliases and voice settings are kept.

Requirements: Windows 10/11, 64-bit, and a microphone for voice commands. Voice recognition runs fully offline.

## Notes

- New third-party libraries: pystray (LGPL-3.0, unmodified) and Pillow (MIT-CMU). They are listed in `THIRD_PARTY_NOTICES.txt`.
- If Windows SmartScreen shows a warning, click **More info**, then **Run anyway**. The installer is not code-signed.
