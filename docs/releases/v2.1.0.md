# AutoH v2.1.0

Voice commands can now control your computer: volume, closing apps, lock, sleep, shut down and restart. AutoH also finds many more of your apps, and it asks instead of guessing when a name is unclear.

Everything still runs offline. Nothing you say leaves your computer.

## New: system commands

| Say | What happens | Asks first? |
|---|---|---|
| "เสียง 30", "ตั้งเสียงเป็นห้าสิบ", "volume 80" | Sets the volume | No |
| "เพิ่มเสียง", "ลดเสียงอีก 20", "เสียงเบาลง" | Changes the volume (10% if you give no number) | No |
| "ปิดเสียง" / "เปิดเสียง" | Mutes / unmutes | No |
| "ล็อกเครื่อง", "lock screen" | Locks the computer | No |
| "ปิด chrome", "ปิดโปรแกรมไลน์" | Closes the app, like clicking ✕ | Yes |
| "พักเครื่อง", "sleep" | Puts the computer to sleep | Yes |
| "ปิดเครื่อง", "รีสตาร์ท" | Shuts down / restarts | Yes, then a 30-second countdown you can cancel |

- Numbers work as Thai words too: "สามสิบ", "ยี่สิบห้า".
- Closing an app never force-quits it. The app can still ask you to save your work. Apps that minimize to the tray, such as LINE or Discord, may only hide their window.
- AutoH never closes Windows system processes or itself.
- You can turn each system command on or off in **Voice Settings → ทั่วไป**. All are on by default.

## Finds more apps

- **Microsoft Store apps** now open by voice: Notepad, Calculator, Paint, Snipping Tool, Terminal, Photos, Claude, Slack and more.
- **Fixed:** many Start Menu shortcuts were wrongly filtered out, for example Discord, VS Code, Steam and Zoom. They are found now.
- New Thai names: "เครื่องคิดเลข", "โน้ตแพด", "เพ้นท์", "เทอร์มินัล", "vs code".
- The app list is rescanned once, automatically, the first time v2.1 starts.

## Fewer wrong guesses

- When a heard name matches very little, or several apps match about equally, AutoH asks or shows a list. For example, "เปิดโน๊ด" no longer opens OneNote without asking.
- If you answer "no" to a guess, the list opens so you can pick the right app. AutoH remembers your choice, and the next time that word opens the app right away.
- The list now shows up to 6 apps.

## Install or update

1. Quit AutoH from the tray menu, or press `Ctrl+Alt+Q`.
2. Download `AutoH-Setup-2.1.0-window-version-64.zip`, unzip it and run `AutoH-Setup-2.1.0.exe`.
3. It installs over v2.0.x for your user only, with no administrator rights. Your modes, aliases, voice settings and history are kept.

Requirements: Windows 10/11 64-bit, and a microphone for voice commands.

## Notes

- New third-party libraries: pycaw and comtypes (both MIT), used for volume control and reading shortcuts. They are listed in `THIRD_PARTY_NOTICES.txt`.
- If Windows SmartScreen shows a warning, click **More info**, then **Run anyway**. The installer is not code-signed.
